# Knowledge Observatory

The Observatory is an explorable information instrument built over the shared Asteria model and deterministic retrieval result. This folder owns its composition, typography, SVG projections, query choreography, version rail, evidence inspector, and interaction grammar; it does not add those choices to shared UI.

The three projections are deliberately different:

- Organization groups all 128 documents around seven departments, nine repositories, and 15 projects.
- Relationship isolates the people, decisions, documents, and departments connected to Project Atlas.
- Evidence shows only accessible current passages, declared lineage, citations, and anonymous access-horizon markers.

Run `npm run capture:observatory` against a preview server on port 4174 to reproduce the four-palette, six-state review matrix in `artifacts/observatory/`.
