# Accessibility strategy

Accessibility is part of each direction's interaction model.

## Non-negotiable behavior

- A semantic heading and landmark structure exists without canvas.
- Every control is keyboard reachable and has a visible, palette-specific focus state.
- Direction, palette, identity, time, query, claim, source, and form changes have programmatic names and predictable focus behavior.
- Retrieval progress and final supported/refusal status are announced without repeatedly reading decorative state changes.
- Evidence state is expressed by text/iconography/pattern or position as well as color.
- Citation inspection exposes structured passage, document, repository, owner, version, access, and sync information.
- At 200% zoom and narrow widths, content reflows without two-dimensional page scrolling.
- The static representation is a first-class view, not an error message.

## Reduced motion

Reduced motion removes camera travel, parallax, path flow, gathering physics, and scroll scrubbing. State changes use instant replacement or brief opacity changes without spatial displacement. The full query, identity, history, citation, and form workflows remain available.

## Spatial equivalents

- Observatory clusters also exist as grouped semantic lists with relationship summaries.
- Institutional OS graphics mirror the source/claim relationships already expressed in the workspace.
- Living Archive layers also exist as an ordered record and version-history outline.
